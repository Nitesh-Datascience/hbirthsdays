# Interactive Birthday Gift 🎂

A self-contained birthday greeting with a pink text-reveal animation, an opening birthday note, confetti, and optional synthesized music.

## Run

1. Choose **Code → Download ZIP** and extract the downloaded ZIP.
2. Double-click `index.html` to open the gift in your browser.

No Python, Node.js, npm, installation, or external assets are required. The page works offline.

## Personalize the gift

Open **Make it personal** below the card. Enter the birthday person's name, your name, and a message, then choose **Apply changes**.

Changes are saved in that browser. To give someone a file containing your message, choose **Download personalized HTML** and send the downloaded HTML file. It contains the complete greeting, styles, and JavaScript.

You can also edit the JSON inside `<script id="card-data" type="application/json">` near the bottom of `index.html`. Keep the JSON valid; use `\n` for new lines.

## Controls

- **Open my gift:** open the birthday message.
- **Replay:** restart the text-reveal animation.
- **More confetti:** create another confetti burst.
- **Sound off / Sound on:** control the optional synthesized birthday tune and chimes.
- **Escape:** close the birthday note.

The interface supports phones and desktops, keyboard controls, and the system's reduced-motion preference. Audio begins only after the sound button is selected.
